# Reference library: source books and extracted plates

Scanned source books (public-domain, from archive.org) and plate pages extracted from them for the
drawing-to-STL tools (sketch2stl, plan2stl, massing.py) and the cathedral buttress / vault work.

Plates are **unedited** 300 dpi page renders: no cropping, thresholding or cleanup.
File names give the **PDF page number**, not the page number printed in the book.
