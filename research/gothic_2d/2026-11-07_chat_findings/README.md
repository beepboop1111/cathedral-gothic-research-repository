# Gothic 2D historical tracing and tracery-to-stonework research — R01 publication

**Published:** 2026-11-07 | **Status:** EXPERIMENTAL / FOR REVIEW

This research branch preserves recoverable findings, repeatable scripts,
measured SVGs, numerical registers, visual references and documentation
from the Gothic tracing development conversation.

**Publication is not architectural approval.** None of these documents replaces
an approved cathedral generator or alters F5ZK-C, F5ZN-A, Pass 6J, the 1:1
architectural baseline, working inner/middle vaults or missing F5ZL-C supports.

## Navigation

## Architectural and image-status rules
- Historical plate drawings are sources, not necessarily proven 1:1 geometry.
- Generated illustrations are visual references, not an exact CAD source.
- Pixel-derived SVG tracing is separate from a verified circular-arc construction.
- Circle fit RMS on arc samples does not prove cusp closure or tangencies.
- One connected 2D stone region does not certify watertight or structural 3D geometry.
- All historic source images, source geometry and cathedral locks remain protected.

Drawing conventions: black solid confirmed geometry, thin dashed light-gray
construction axes, dotted black full recovered circles, red dashed uncertainty.
Orange for open candidate faces, green for closed candidate faces, purple/blue
through warmer colors for visual layers, *not physical masonry depth*.

## Public GitHub scope
Large original historical book-scan ZIP archives, redundant compressed
packages, bulky STLs, and unrelated downloads were excluded from this
public Git branch. The source archive catalog records SHA hashes, sizes
and exclusions. The giant Research_02 plate ZIP exceeds GitHub's normal
per-file limit and requires a deliberate archive release/licensing review.

No file was modified in its original source location on MR COMPUTER.
No experimental generator was promoted to an approved architectural baseline.
