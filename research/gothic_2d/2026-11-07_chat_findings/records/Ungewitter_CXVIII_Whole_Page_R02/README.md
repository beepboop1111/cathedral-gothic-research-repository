## Research limitations
This is a faithful image-derived **whole-page trace**, not a set of mathematically recovered circular arcs. SVG outlines are vector boundaries of historic printed ink. In the annotated version, light-gray dividing axes are a distinct optional layer approximated from visible figures and are not claimed as printed historical axes. No red dashed hypothetical curves are included, because this pass introduces no speculative compass geometry. Original black historical guide strokes remain faithfully preserved. No scaling to actual architecture is implied. Existing generators and locked cathedral parameters are unchanged. Candidate for user review, not approved for promotion.
