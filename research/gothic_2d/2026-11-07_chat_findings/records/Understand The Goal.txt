## Gothic 2D — Workflow Integration R01

The first integration is working. **QF-001, the five experimental workflows, and the six existing Ungewitter traces now share one geometry interface.**

The adapter accepts 12 construction records without modifying their original source scripts.

| Existing work | Connected function | Status preserved |
|---|---|---|
| QF-001 | Generate exact four-lobed geometry at chosen dimensions | Approved 2D |
| W01–W05 | Recover foil arcs, circles, rings, and pointed-arch elements; scale uniformly | Experimental |
| Figures 1193–1198 | Import existing SVG linework and construction layers | Traced, not analytically verified |
| Gothic V08 | Cross-check circle fitting and geometric transformations | Experimental toolkit |

The initial integration has passed **12 automated tests**, including regenerating all five experimental workflow SVGs byte-for-byte from their original script.

This means we have demonstrated reuse without having to redraw or independently recreate the existing constructions.

One limit remains: a successful file or geometry test does not make W01–W05 historically accurate or ready for 3D stonework. Their existing approval boundaries remain in force.

### How the integrated engine works

You can now use one command interface to select an existing construction and generate a standardized SVG plus structured geometry JSON.

For example:

```bash
python integrated_2d.py --list
python integrated_2d.py --id W02 --scale 1.5 --out my_output
```

The shared format carries geometry, parameters, source checksums, numerical measurements, and approval status.

**What remains:** The mathematical and historical validation of W01–W05, the original-source verification of figures 1193–1198, and later connection to the 3D generators.

The Master Research Register R01, approved QF-001 source, historical material, and cathedral geometry remain unchanged.

**This integration is ready for your review, not yet a newly approved permanent checkpoint.** Once you approve the interface, we can adopt it as our common working foundation for future 2D constructions.
