# Pass 6J V11/V6 station-frame and tas-de-charge source recovery R02
Date: 2026-11-09. **Non-destructive recovered-source record, not an architectural approval.**

## Recovered originals
The six original Python files in this folder cover the early Pass 6J circular arch and spring-tangent diagnostic, profile-sweep and station-frame variants, pier alignment, and the R1@78° first Gothic springing set-out. The 2D pier script is **not** a complete 3D tas-de-charge mesh generator; the diagnostic bay-frame script is **not verified** as the exact final V6/V11 production exporter.

## V12 evidence
The project reused V11/V6 arch paths, vertical-tangent springs at Y=3000, straight responds and locked pier/tas/webs, changing D-ogive/doubleau profiles only. D ogive: width 36.000118, depth 59.892342; doubleau: width 38.160168, depth 64.675593. Both have 27.8% central moulding event and 15.8% each flanking channel. Exact final V12 exporter **unverified**.

## First R1@78° tas experiment
Radii R0=2933, R1=4181, R2=4901, R3=5957. Four major arches plus four ogives, derived from asymmetric actual bearings. Original 2D section set-out has experimental (rise→lateral release): 0→0, 40→0, 80→6, 120→14, 160→24, 220→35, 300→45, 400→60. This schedule is **not approved final rib geometry**.

Later project records: original-derived eight-member common shaft/springing union at Y3000 to approximately Y3260; articulated pier V1, narrow/smooth V2 and S1 straight-respond termination Y2880 instead of Y2700. Later V2 3D generator source remains **not recovered**.

## Separate R4085 / F5ZN-A springer
A different historical archive on MR.COMPUTER contains genuine `build_profile_driven_sommiers.py` and `build_tapered_source_section_courses.py` (C1/C2, five courses Y3000–3300). C2 bedding boundaries were matched, but fine top-cap/rib contact remained unresolved. **Do not transfer those R4085 experimental dimensions to Pass 6J R1=4181.**
