## Continuous web construction

The preserved R13 mathematical source generates the original six
sector surfaces H13(k,t,s). Only for Sector 05:

    H14(5,t,s) = H13(5,t,s)
            + sin(pi*t)^2 * [ M_B(s) - H13(5,0.5,s) ]

where M_B is the user's registered Type B Hermite curve.
This correction vanishes precisely on all original Gothic boundary
arches, both neighboring groins, and the Z4296 boss. All other five
sectors remain exact R13 geometries.

The mesh is intentionally an OPEN intrados with 98,304 triangles,
consistently wound and connected. A closed construction masonry solid
is not attempted because Type A still rises above the old cap.
